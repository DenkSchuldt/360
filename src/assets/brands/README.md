# Social brand icons

These three SVGs are vendored from the official **Simple Icons** repository,
release **15.8.0**, retrieved on 2026-10-17. Only `fill="#fff"` and a final newline
were added for the white app-bar treatment; the 24 × 24 view boxes and original
path data are unchanged. They are bundled locally, with no runtime icon package
or third-party image request.

## Exact sources

- GitHub: https://github.com/simple-icons/simple-icons/blob/15.8.0/icons/github.svg
- X: https://github.com/simple-icons/simple-icons/blob/15.8.0/icons/x.svg
- Instagram: https://github.com/simple-icons/simple-icons/blob/15.8.0/icons/instagram.svg
- Metadata: https://github.com/simple-icons/simple-icons/blob/15.8.0/data/simple-icons.json

The metadata identifies these original brand sources and guidelines:

- GitHub: https://github.com/logos
- X source: https://x.com; guidelines: https://about.x.com/en/who-we-are/brand-toolkit
- Instagram: https://about.meta.com/brand/resources/instagram
